## 1. 科学问题与假说（冻结）

**H-D16C**：将 within-source 候选密度从 1.7-6.1 提升到 ≥32（含结构多样性 ≥5 键/源），可以把 V5 家族的"记忆路线"逼到"结构路线"——可测量预测：train-backtest gap 从 0.59-0.79 收缩到 < 0.30，且 VALIDATION ρ 不降（MRL ≥ 0.135 基线）。

**反假说（可证伪）**：如果 gap 不收缩，说明 170M 端到端模型在结构数据充足时仍选记忆路线（容量性记忆偏好）——那 ERK 参数侧（显式结构先验）成为唯一路径，数据侧宣告独立无效。

## 3. 合成候选生成协议（插值纪律——防循环污染的硬条款）

**3.1 生成方式（结构对齐，非监督对齐）**：
- 对每个 TRAIN 源：从该源**实测邻域**的编辑结构轮廓（编辑数 × 窗位 span，D15-2 结构键协议）采样结构键；窗内位置与替换碱基随机
- 每源生成至 32 候选（含实测的 4.9-6.1 个，即合成 ~27/源）
- **硬条款 H1（插值不进监督目标）**：合成对的**标签不使用任何模型预测值**（包括 V5/外部 critic 的插值）。合成对仅以**结构增强成员**身份进入训练——其 loss 权重固定为 0（只参与表征正则/对比结构，不监督回归）。监督目标 100% 来自实测行。
  - 理由：train-backtest 已证 V5 会记忆；若用 V5 插值标签训后继，等于把记忆固化进数据。结构增强的机制是"迫使表征在源内多候选间做区分"，这个机制不需要标签。
- **硬条款 H2（替代监督形态，若需要非零标签）**：唯一允许的合成标签形态 = within-source **对比目标**（合成候选与实测候选的相对排序留空，仅用于 InfoNCE/排序一致性正则项——此时合成对进 loss 的唯一通道是"与实测对的相对结构一致性"，仍不携带绝对值）。任何把回归标签写进合成行的实现 = 协议违规，执行者必须拒绝执行并上报。

**3.2 生成器种子与可复现性**：seed 20260913 固定；结构键采样器与 D15-2 pipeline（`run_d15_2_pipeline.py`）同源，逐源记录生成 trace（`synthetic_trace.jsonl`：源 ID × 结构键 × 随机数种子）。

**3.3 泄漏审计前置（硬门）**：合成候选与 VALIDATION 实测候选的序列 exact-match 检查——flagged > 0 则剔除该合成对（D2 审计协议复用）；合成不触碰 TEST（protected reads = 0 维持）。

## 4. 训练与验收（冻结判定门）

**4.1 训练配置**：V5 血统修复模式（D13-b 五原则逐行适用）：V5 终态 checkpoint 为 init（修复不换血）；合成对 loss 权重 0（H1）或对比通道（H2）；其余超参照抄 V5 screen config；1 seed 首发探针臂（~6 GPU·h），过门再 3-seed。

**4.2 判定门（发射前冻结，禁止事后调整）**：

| 门 | 判据 | 通过动作 |
|---|---|---|
| **G1 泛化改善** | MRL train-backtest gap ≤ 0.30（现 0.79）且 VAL ρ ≥ 0.135（V5 基线） | 过 → 3-seed 确认 |
| G2 不破坏 | polyA VAL ρ ≥ 0.80（非破坏门，V5 0.8219 的 0.98 倍） | 破坏 → 一票否决回炉 |
| G3 反假说登记 | G1 FAIL 且 gap > 0.5 | 如实入档"数据侧独立无效"，ERK 参数侧成为唯一路径 |
| G4 结构探针 | 合成增强后 V5 在**结构池**内 graded sc-hit@1 > 0（现 0.0，D15-2） | > 0 = 表征开始学结构的直接证据 |

**4.3 检验力条款**：HL 天花板 ≈0，HL 门只看 gap 收缩不看绝对 ρ（gap 是记忆诊断量与天花板无关）；MPRAU 判 pair-mean 口径。

## 5. 边界声明（本 amendment 不做什么）

- 不改 V5 架构组件（MoE/头/损失）——那是 V6-V9 已证伪的行级优化
- 不含 ERK v2 训练臂（参数侧另立 amendment；本协议的合成数据管线两者共用）
- 不动 polyA（已达标）；不触 TEST；预注册门槛不事后改
- 合成数据 ≠ 新监督数据：若未来获得真实新库（如 GSE114002 designed-lib 扩充），真实数据优先于合成
